# 🤖 내 몸 탐험 위키 (robot_rehab)

AI 친구와 함께 **논문 PDF를 읽고 정리해서 위키와 비교표(Literature Matrix)를 만드는** 수업 실습 자료입니다.

**우리 연구 질문:** 운동하면 어린이 맥박은 얼마나 오르고, 쉬면 얼마나 빨리 돌아올까?

> ⚠ `papers/`에 있는 논문 4편은 수업용으로 만든 **연습용 가상 논문**이에요. 실제 논문이 아닙니다.

---

## 📦 1. 내 컴퓨터로 받기

1. 이 페이지 위쪽의 초록색 **`<> Code`** 버튼 → **Download ZIP**을 누릅니다.
2. 받은 zip의 압축을 풉니다. 폴더 이름이 `robot_rehab-main`으로 나옵니다.
3. 그 폴더 **안의 내용물**을 아래 위치의 `robot_rehab` 폴더로 옮깁니다.

| 내 컴퓨터 | 폴더를 둘 위치 |
| --- | --- |
| Windows | `C:\robot_rehab` |
| Mac | 홈 폴더의 `robot_rehab` (`~/robot_rehab`) |

4. `robot_rehab` 폴더를 열었을 때 **`CLAUDE.md`와 `실습지.md`가 바로 보이면** 성공입니다.

자세한 단계(사진 대신 글로 하나하나)는 👉 [**학생 설치 가이드**](학생_설치_가이드.md)를 보세요.

---

## 💻 2. VS Code에서 열기

1. VS Code → **파일(File) → 폴더 열기(Open Folder)** → `robot_rehab` 선택
2. "작성자를 신뢰하십니까?" → **예**
3. AI 채팅창에 이렇게 입력해 보세요.

```
CLAUDE.md 를 먼저 읽고, 이 위키가 무엇인지 쉽게 설명해 줘.
```

AI가 "내 몸 탐험 위키"에 대해 설명하면 준비 끝! 이제 [`실습지.md`](실습지.md)를 열고 미션 1부터 시작해요.

---

## 🗄️ 3. 폴더 안에 무엇이 있나요?

```
robot_rehab/
├─ CLAUDE.md            ← AI 친구가 제일 먼저 읽는 규칙장
├─ 실습지.md             ← 오늘 할 미션 1~5
├─ 학생_설치_가이드.md    ← 설치가 안 될 때 보는 곳
├─ papers/              ← 논문 PDF 원본 (읽기만! 고치지 않기)
└─ llm_wiki/            ← AI와 함께 정리해서 쓰는 위키
   ├─ README.md         ← 서랍 사용 규칙
   ├─ index.md          ← 위키 목차
   ├─ log.md            ← 변경 일기
   ├─ open_questions.md ← 아직 모르는 것 모음
   ├─ papers/           ← 논문 1편 = 페이지 1장 (DOI 있는 논문만)
   ├─ concepts/         ← 낱말 설명 (예: 맥박)
   └─ research/맥박_연구/ ← 우리 연구 공간 + 비교표(literature.md)
```

오늘 배울 흐름: 📄 PDF 원본 → 📝 논문 페이지 1장 → 📊 비교표 한 줄

## 🆘 안 될 때

| 증상 | 해결 |
| --- | --- |
| AI가 "파일을 찾을 수 없다"고 해요 | 파일 하나가 아니라 **`robot_rehab` 폴더째** 열었는지 확인 |
| 폴더 안에 `robot_rehab-main` 폴더가 또 있어요 | 안쪽 폴더의 **내용물**을 바깥으로 꺼내기 |
| 한글 파일 이름이 깨져요 (Windows) | zip을 반디집 등 압축 프로그램으로 다시 풀기 |

더 많은 해결 방법은 [학생 설치 가이드](학생_설치_가이드.md)의 마지막 표를 보세요.
